# 🏥 Чат-бот для лікарні

Чат-бот на Streamlit з двома інструментами:

- **Pinecone** — пошук за документами лікарні (векторна БД)
- **Supabase** — SQL-запити до даних лікарні (реляційна БД, `SQLDatabase`)

## Файли

- `main.py` — Streamlit-застосунок з агентом
- `data_base.py` — створення баз даних
- `paragraph_splitter.py` — розбиття документів на розділи
- `general.txt`, `for_workers.txt` — документи лікарні
- `ids` — ID розділів

## Запуск

```bash
pip install -r requirements.txt
```

Створіть `.env` з ключами:

```env
GEMINI_API_KEY...
PINECONE_API_KEY=...
SUPABASE_DB_URL=...
DATABASE_URL=...
```

```bash
python data_base.py
streamlit run main.py
```

## Як це працює

**Векторна БД:** документи читаються, розбиваються на розділи, до метаданих додається поточний час, розділи завантажуються в Pinecone, а їхні ID зберігаються у файл `ids`.

**Реляційна БД:** у Supabase створено кілька пов'язаних таблиць (SQL-запити з практичних занять). Агент працює з ними через `SQLDatabase`.

Агент сам обирає, який інструмент використати для відповіді.
